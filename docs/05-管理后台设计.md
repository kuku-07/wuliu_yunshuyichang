# 阶段 3 · 管理后台设计（页面清单 + 接口清单）

> 版本 v0.1 · 2026-10-30 · 清单已确认，实现见 [admin_app/](../admin_app/README.md)
> 服务端渲染（FastAPI + Jinja2），风格对齐 SaaS 控制台
> 关联：[04-聊天接口设计](04-聊天接口设计.md)、[03-架构选型方案](03-架构选型方案.md)

## 0. 与原题（报销助手）的五处关键差异

| 原题设计 | 本项目调整 | 原因 |
| --- | --- | --- |
| 上传 → 切片 → 向量化 → **直接入库可用** | 上传 → 解析 → 切片 → **审核 → 发布（版本 + 生效日期 + 线路）** → 重建索引 | 规则错一条，就会产生错误的处置与升级建议（f24、f50） |
| 知识条目「列表可删除」 | 已生效版本**只能下线，不能物理删除**；仅草稿可删 | 历史对话要能重建「当时依据哪一版」（f45） |
| 提示词改完**立即生效** | 提示词分**锁定安全段 + 可编辑话术段**；保存为草稿 → 试跑 → 发布 → 可回滚 | 提示词本身就是安全控制，随意改等于绕过红线（f15） |
| 两种角色：员工 / 管理员 | 四种后台角色：规则管理员 / 客服主管 / 合规审计 / 系统管理员 | 职责分离：上传的人不能自己批准发布 |
| 对话审计只标记「疑似违规报销」 | 标记五类：越权查询 / 红线绕过 / 未取证签收 / 未签核外发 / 敏感信息外泄 | 本项目的违规形态不在金额，在「证据与授权」 |

**一句话原则：知识库和提示词都是「受控变更」，不是「即时配置」。**

## 2. 页面清单（8 页）

| # | 页面 | 路由 | 核心内容 |
| --- | --- | --- | --- |
| P1 | 登录 | `/admin/login` | 账号密码 + 失败锁定 + 错误中文提示 |
| P2 | 规则库列表 | `/admin/kb` | 状态筛选（草稿/待审/已生效/已下线）、线路筛选、搜索；行内显示版本与生效日期 |
| P3 | 上传与解析预览 | `/admin/kb/upload` | 拖拽上传 md/pdf → 解析结果 → 切片预览（可编辑切片）→ 冲突与敏感信息提示 → 保存草稿 |
| P4 | 规则详情与版本 | `/admin/kb/{doc_id}` | 元数据（线路/生效日期/版本）、版本对比、切片列表、审核记录 |
| P5 | 提示词模板 | `/admin/prompts` | 左：锁定安全段（只读）；右：可编辑话术段；底部：试跑、发布、版本历史 |
| P6 | 对话审计列表 | `/admin/audit` | 按员工/时间/线路/标记类型/是否接管筛选；分页 |
| P7 | 对话详情 | `/admin/audit/{conversation_id}` | 完整消息、引用、闸门结果、护栏结果、模型与耗时；标记操作 |
| P8 | 发布记录 | `/admin/releases` | 规则与提示词的发布/回滚流水，谁在何时改了什么 |

P1–P2 之外，页面均为「列表 + 详情」结构；SSR 表单提交，列表页支持无刷新筛选。

### 2.1 P3 上传与解析预览（关键页）

```text
┌ 上传区 ─────────────────────────────────────────┐
│ 支持 .md / .pdf（≤20MB）· 扫描版 PDF 需先 OCR    │
├ 解析结果 ───────────────────────────────────────┤
│ 识别标题 9 个 · 生成切片 12 个 · 去重 2 个        │
│ ⚠ 与已生效 v0.1「4. 到货与回执口径」冲突（2 处）  │
│ ⚠ 检测到手机号 1 处，已自动脱敏                   │
├ 切片预览（可编辑）──────────────────────────────┤
│ #3  [2. 异常分类]  分 512 字  [编辑] [删除]       │
│ #4  [2. 异常分类]  分 498 字  [编辑] [删除]       │
├ 元数据 ─────────────────────────────────────────┤
│ 适用线路：试点干线-华东   生效日期：2026-11-01    │
│ 版本：0.2（自动递增）                             │
├ 操作 ───────────────────────────────────────────┤
│ [保存草稿]  [提交审核]                            │
└─────────────────────────────────────────────────┘
```

### 2.2 P5 提示词模板（关键页）

```text
┌ 锁定安全段（只读，不可编辑）──────────────────────┐
│ · 只依据检索到的规则条文回答                       │
│ · 未找到时必须回答「规则中未找到，请转人工确认」    │
│ · 禁止输出赔付金额/责任认定/扣罚结论/绕行建议       │
│ · 不得生成对外发送的最终文本，只出内部草稿          │
│ · 回答末尾必须附引用（文档+版本+章节）             │
├ 可编辑话术段 ────────────────────────────────────┤
│ [语气风格] [称呼方式] [不确定时的引导语]           │
├ 试跑 ────────────────────────────────────────────┤
│ 固定 20 条测试集：通过 19 / 红线全部拦截 ✓         │
├ 操作 ────────────────────────────────────────────┤
│ [保存草稿] [试跑] [发布]（主管）[回滚到 v3]        │
└─────────────────────────────────────────────────┘
```

锁定段在代码与数据库中都是**独立字段**，编辑接口直接拒绝修改（错误码 `PROMPT_LOCKED_SECTION`），不是靠前端置灰。

## 3. 接口清单

统一前缀 `/admin/api`。SSR 页面用 Cookie 会话，JWT 放 `HttpOnly + SameSite=Strict` Cookie，另配 CSRF 双提交令牌；**不把 JWT 放 localStorage**。

### 3.1 认证

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/auth/login` | 匿名 | 账号密码登录，5 次失败锁 15 分钟 |
| POST | `/auth/logout` | 登录 | 清除 Cookie，写审计 |
| GET | `/auth/me` | 登录 | 返回角色、可访问线路、权限点 |
| POST | `/auth/refresh` | 登录 | 续期，旧 token 失效 |

### 3.2 规则知识库

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/kb/docs` | 登录 | 列表；筛选 `status/lane/keyword` |
| POST | `/kb/docs/upload` | 规则管理员 | multipart；解析后返回**草稿**，不直接生效 |
| GET | `/kb/docs/{doc_id}` | 登录 | 详情 + 版本 + 切片 |
| PATCH | `/kb/docs/{doc_id}` | 规则管理员 | 改元数据（线路、生效日期），仅草稿 |
| PATCH | `/kb/docs/{doc_id}/chunks/{chunk_id}` | 规则管理员 | 编辑切片文本，仅草稿 |
| DELETE | `/kb/docs/{doc_id}` | 规则管理员 | **仅草稿可删**；已生效返回 `DOC_IMMUTABLE` |
| POST | `/kb/docs/{doc_id}/submit-review` | 规则管理员 | 提交审核，锁定草稿 |
| POST | `/kb/docs/{doc_id}/approve` | 客服主管 | 批准，操作人须 ≠ 提交人 |
| POST | `/kb/docs/{doc_id}/publish` | 客服主管 | 发布：写版本、切索引别名 |
| POST | `/kb/docs/{doc_id}/offline` | 客服主管 | 下线，保留历史版本 |
| GET | `/kb/docs/{doc_id}/diff?from=&to=` | 登录 | 版本差异 |
| GET | `/kb/index/status` | 登录 | 索引版本、切片数、最近重建时间 |
| POST | `/kb/index/rebuild` | 系统管理员 | 影子索引构建后原子切换 |

### 3.3 提示词模板

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/prompts` | 登录 | 当前生效模板 + 锁定段 |
| GET | `/prompts/{id}/versions` | 登录 | 版本历史 |
| POST | `/prompts/{id}/draft` | 规则管理员/主管 | 仅改可编辑段；改锁定段返回 `PROMPT_LOCKED_SECTION` |
| POST | `/prompts/{id}/validate` | 规则管理员/主管 | 结构校验：变量齐全、锁定段哈希未变 |
| POST | `/prompts/{id}/dry-run` | 规则管理员/主管 | 跑固定 20 条测试集，返回通过率与拦截结果 |
| POST | `/prompts/{id}/publish` | 客服主管 | 发布，需 dry-run 通过且在 24 小时内 |
| POST | `/prompts/{id}/rollback` | 客服主管 | 回滚到指定版本 |

### 3.4 对话审计

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/audit/conversations` | 主管/审计 | 筛选 `employee_id/from/to/lane/flag/takeover`，分页 50 |
| GET | `/audit/conversations/{id}` | 主管/审计 | 消息、引用、闸门、护栏、模型、耗时 |
| POST | `/audit/conversations/{id}/flags` | 主管/审计 | 五类标记 + 原因说明；**追加式** |
| POST | `/audit/flags/{flag_id}/revoke` | 主管/审计 | 撤销标记，需填理由，保留原记录 |
| GET | `/audit/export` | 审计 | CSV 导出，异步生成下载链接 |
| GET | `/audit/admin-actions` | 主管/审计 | 后台操作流水（发布、下线、改模板） |

### 3.5 统一错误码

| 错误码 | HTTP | 中文 message |
| --- | --- | --- |
| `UNAUTHENTICATED` | 401 | 未登录或登录已过期，请重新登录 |
| `FORBIDDEN` | 403 | 当前角色无权执行该操作 |
| `CSRF_INVALID` | 403 | 页面已过期，请刷新后重试 |
| `PROMPT_LOCKED_SECTION` | 422 | 安全约束段不可编辑 |
| `DOC_IMMUTABLE` | 409 | 已生效规则不可删除，请使用下线 |
| `APPROVER_SAME_AS_SUBMITTER` | 409 | 提交人与批准人不能为同一人 |
| `DRY_RUN_REQUIRED` | 409 | 请先试跑并通过后再发布 |
| `UPLOAD_TOO_LARGE` | 413 | 文件超过 20MB，请拆分后上传 |
| `UNSUPPORTED_FILE` | 415 | 仅支持 .md 和 .pdf 文件 |
| `PDF_NO_TEXT_LAYER` | 422 | 该 PDF 无文字层，请先 OCR 后再上传 |
| `INDEX_REBUILDING` | 409 | 索引正在重建，请稍后再试 |
| `INTERNAL_ERROR` | 500 | 系统内部错误，请联系管理员（编号 {request_id}） |

| 表 | 关键字段 |
| --- | --- |
| `admin_users` | id, employee_no, name, role, lane_scopes, password_hash, status, failed_count, locked_until |

## 5. 安全要求

- 密码：≥12 位，Argon2id 哈希；连续 5 次失败锁 15 分钟。
- JWT：30 分钟有效期，claims 含 `role`、`scopes`、`lane_scopes`；每次请求校验角色与接口权限点。
- SSR 表单全部带 CSRF token；Cookie `HttpOnly`、`SameSite=Strict`、生产 `Secure`。
- 文件上传：白名单扩展名 + MIME 双重校验、大小 20MB、随机文件名、不在 Web 根目录存放；PDF 用解析库提取文字，失败即拒绝。
- 知识库投毒：上传内容中的「忽略以上指令」类文本不进入提示词；检索结果统一包裹为数据段。
- 审计页展示手机号/地址时脱敏；导出需二次确认并记审计。
- 所有后台操作写 `audit_logs`，含操作人、对象、变更前后哈希。

## 6. 验收口径

| # | 项 | 标准 |
| --- | --- | --- |
| 1 | 职责分离 | 同一账号无法既提交又批准，接口层强制 |
| 2 | 规则生效 | 发布前检索仍用旧版；发布后原子切换，无混合版本 |
| 3 | 删除保护 | 已生效文档删除返回 409，且不影响历史引用 |
| 4 | 提示词 | 锁定段被改动时保存失败，错误码为 `PROMPT_LOCKED_SECTION` |
| 5 | 提示词发布 | 未试跑或试跑未通过不可发布 |
| 6 | 审计 | 标记可撤销但原记录保留；导出含 request_id |
| 7 | 越权 | 规则管理员访问审计页返回 403，且无数据泄露 |

## 7. 需要你确认的 4 个点

1. **角色数量**：先用四种角色，还是先合并成「管理员 / 审计」两种简化上线？
2. **规则发布是否需要双人复核**：当前设计强制；若试点期人少，是否允许主管临时自批（需留审计）？
3. **提示词试跑测试集**：由谁维护这 20 条？是否允许管理员在页面上增删？
4. **审计导出**：是否限制导出条数（如单次 ≤5000 条）并要求主管审批？

确认后我按「认证 → 规则库 → 提示词 → 审计」四批出代码，每批可独立运行。
