# 管理后台（阶段 3）

服务端渲染的 SaaS 风格后台，覆盖四批能力：

1. 登录鉴权（JWT Cookie + 角色权限 + CSRF）
2. 规则知识库（上传 → 解析 → 切片 → 审核 → 发布 → 索引切换）
3. 提示词模板（锁定安全段 + 草稿 → 试跑 → 发布 → 回滚）
4. 对话审计（筛选 → 详情 → 标记 → 导出 → 发布记录）

设计依据：[docs/05-管理后台设计.md](../docs/05-管理后台设计.md)

## 启动

```powershell
.\run_admin.ps1
```

打开 <http://127.0.0.1:8088/admin/login>。

## 说明

- 数据库与上传文件位于 `admin_app/data/`，首次启动自动建表并写入演示数据。
- 上传仅支持 `.md` / `.pdf`（≤20MB）；无文字层的扫描 PDF 会被拒绝。
- 提示词锁定段在数据库字段层不可修改，接口会拒绝并返回 `PROMPT_LOCKED_SECTION`。
- 审计标记为追加式，撤销保留原记录。
- 本目录只实现阶段 3；阶段 2 的 `/chat` SSE 服务尚未接入，审计页使用演示会话数据。
