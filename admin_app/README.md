# 管理后台（阶段 3）

服务端渲染的 SaaS 风格后台，覆盖五批能力：

1. 登录鉴权（JWT Cookie + 角色权限 + CSRF）
2. 一线问答（`/admin/chat`：SSE 流式、红线接管、引用面板，见阶段 2）
3. 运单登记（`/admin/shipments`：运单主数据增删改、演示数据一键清除/恢复）
4. 运单级授权（`/admin/grants`：谁可以查哪一票；授权自动绑定运单归属线路，仅系统管理员）
5. 规则知识库（上传 → 解析 → 切片 → 审核 → 发布 → 索引切换）
6. 提示词模板（锁定安全段 + 草稿 → 试跑 → 发布 → 回滚）
7. 对话审计（筛选 → 详情 → 标记 → 导出 → 发布记录）
8. 数据管理（演示数据逐条删除 / 按组恢复，仅系统管理员）

其中「一线问答」的规则检索走的是知识库里**已生效**的切片，提示词走模板的**已发布**版本；
问答产生的消息、引用与审计事件都会落库，所以「对话审计」页展示的就是真实会话。

设计依据：[docs/05-管理后台设计.md](../docs/05-管理后台设计.md)

## 说明

- 数据库与上传文件位于 `admin_app/data/`，首次启动自动建表并写入演示数据。
- 上传仅支持 `.md` / `.pdf`（≤20MB）；无文字层的扫描 PDF 会被拒绝。
- 提示词锁定段在数据库字段层不可修改，接口会拒绝并返回 `PROMPT_LOCKED_SECTION`。
- 可编辑话术段的默认内容是**浅色占位提示**，输入正式话术后即被替换；直接提交空内容会被拒绝。
- 审计标记为追加式，撤销保留原记录。
- 阶段 2 的一线问答已接入：`/admin/chat`，SSE 流式，红线在调用模型前拦截。
